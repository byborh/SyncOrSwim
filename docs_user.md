## Installation

This might look like dev docs, but if you're a user, at some point you need to install the right environment ...

Steps :

1. Install Python 3.7
2. Install virtualenv :
  * `path/to/python.exe -m pip install --upgrade pip`
  * `path/to/python.exe -m pip install virtualenv`
3. Create virtualenv :
  * `path/to/python.exe -m virtualenv path/to/venv`
4. Activate virtualenv :
  * `path/to/venv/Scripts/activate`
5. Install dependencies :
  * `pip install -r requirements.txt`
